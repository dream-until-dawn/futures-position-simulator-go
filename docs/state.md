## ⚠️ 待裁决：`rules_measured` 的升格判据（2026-09-09 提出，**未生效**）

⚠️ **这一节是待裁决，不是已定。** 计数没有按它动过。

判据的候选措辞（评审方提出，实现方已独立复核过下面的数）：

> **第二个独立来源必须能「分开候选」，不能只是「对上数值」。**
> 若几个候选解释在该来源上给出**同一个数**，它对这条规则没有判别力 ——
> 它证的是**数据**，不是**规则**。

它的来历是同一天的一次自我更正：判断某文件换行是否错乱时，
「gofmt 差异正好是两倍」被当成了证据，而**一个真的格式错乱的文件同样是两倍**。
拿同一把尺子去量升格问题，两条现存事实的结论正好相反：

| | 判据下的结论 | 理由 |
|---|---|---|
| `kq_facts` 20（快期昨结算价 == 上期所今结算价）| **不该升格** | 只有一个候选。对不上意味着**数据**错了，不是规则是另一条 |
| `kq_facts` 37（`position_price` 的昨仓基线）| **该升格** | 上期所同一份日行情里**收盘 3177 与结算 3163 并列**，两个候选给出不同预测 |

第 37 条的两个预测（昨 3 手 + 今 1 手 @3166，见 `position-frozen-20260909-5.json`）：

    用收盘价  (3×3177 + 1×3166)/4 = 3174.25   ← 柜台给的就是这个
    用结算价  (3×3163 + 1×3166)/4 = 3163.75

⚠️ **但升格它不会让 1/13 变成 2/13。** §13 的十四行里**没有**一条对应
「`position_price` 的昨仓基线用哪个价」—— 第 37 条不是解决了一条挂着的未知，
是回答了一个**从没被写进清单**的未知。正确记法是两笔一起记：

    rules_pending  +1   本该在册，此前漏了
    rules_measured +1   同一次实测把它解决了
                      → 2 / 14，而不是 2 / 13

> ⚠️ **只记解决、不记发现，分子涨而分母不动，比值会凭空变好看。**

⚠️ **为什么今晚不动**：`rules_measured` 是 tag 门槛之一，改判据等于改闸口宽度；
而**想放松它的动机恰好在它挡路时最强**，今晚它正挡着路且无人在旁。
这条澄清本身是**收紧**（同时否掉第 20 条、通过第 37 条），这正是它像原则
而不像借口的地方 —— 但也正因如此，它值得在有人看着的时候落定。

## `kq_facts`：关于快期模拟这个口子的已实测事实

⚠️ **这一节与 `rules_measured` 是两回事，分开记是刻意的。**

> 这里记的是「**快期模拟怎么实现**」；§13 问的是「**规则是什么**」。
> 前者是后者的证据来源之一，不是后者的答案。

它和「有人去刷 `restatement-count.sh` 那个数」是同一种死法——

### 落成脚本时的「守卫的守卫」

标记本身会写错。2026-09-07 `probes.md` 就出过 `start=3 / end=2`——
把标记「提到标题之前」时加了新的、没删旧的。

⚠️ **这个毛病的失败方向朝着「什么也不报」**：深度计数式实现下，
`probes.md` 结束时 depth=1，若不逐文件重置，按字母序排在它后面的
`roadmap.md` / `silent-risks.md` / `state.md` **会被整体豁免掉**。
0 处不是因为干净，是因为检查在半路闭了嘴。

**一个豁免机制出 bug，比检查本身出 bug 更糟：它让检查更安静，不是更吵。**

所以脚本必须自己断言：

1. 每文件 `start == end`，**不配平直接失败并指出文件名**
2. 不允许嵌套（深度只能是 0 或 1）
3. EOF 时深度归零
4. **逐文件重置块状态**，绝不跨文件带

⚠️ **禁语只防复发，不防首发。** 它是一份对自然语言的黑名单，而黑名单漏一条即静默失效。
禁语从**状态翻转那次提交里被删掉的字符串**中生成——列表由真实编辑长出来，
不由想象力长出来。**首次写出一句新的过期表述，仍然只能靠人眼。**
