### ⚠️ 自指豁免必须在写脚本**之前**定死

拿上面这张表在全库真跑一遍，命中 **6 处**，全部合法：

| 位置 | 为什么合法 |
|---|---|
| `probes.md` 两处 | 历史留档，记录「当时缺什么」 |
| `roadmap.md:143` | **列举禁语的那一句** |
| `roadmap.md:180` | 分析「哪条机制抓得住哪一类」的表 |
| `roadmap.md:354` | 变更记录引用历史原文 |
| 删除线内一处 | 已显式作废 |

⚠️ **一个永远红的检查会被忽略，被忽略的检查等于没有检查。**
它和「有人去刷 `restatement-count.sh` 那个数」是同一种死法——
只是这次死于**噪声**，那次死于**粉饰**。

所以豁免规则现在就定死，**不等它红了再补 `# nolint`**——补出来的豁免会越加越宽：

> **禁语只在「正文叙述行」上生效。** 一行是正文叙述行，当且仅当它
> ① 不在代码块（``` 围栏）内；
> ② 不在历史留档块内。⚠️ **标记的判定是「整行就是它」，不是「行内含有它」**
>   ——本文件在定义标记时必然要提到它们，按「含有」判定会把定义行读成未闭合的
>   块，于是本文件结束时深度不为零。这与「字典必然包含它定义的每一个词」是
>   同一个形状，只是从禁语层跑到了标记层，而它暴露的是**「怎么算一个标记」
>   当时根本没写**——两个实现可以在这里分道扬镳，且两条都读得通；
> ③ 不含删除线 `~~`；
> ④ **位于本文件（`state.md`）内，或含指向 `state.md` 的链接**。

第 ④ 条的后半句是刻意设计的：讲这套机制的段落**本来就该引用唯一来源**。

⚠️ **前半句是补上的，而它暴露了一个形状**：唯一来源建起来之后，
它成了全库**唯一必然违反禁令的文件**——字典必然包含它定义的每一个词。
而规则是在它存在之前写的，所以漏掉了字典自己。

⚠️ 更糟的是这条排除起初**只存在于实现里**：我第一版检查器写了
`if p.endswith('state.md'): continue`，规则里一个字没有。
于是我跑出 0 处、评审跑出 4 处，**分歧的根源不是实现有 bug，是规范缺一条**。
于是豁免不是特批，是**挣来的**——你要谈禁语，就得同时把读者指回 `state.md`。
⚠️ 历史留档的标记也据此从散文（「以下保留原文」）改成了机器可读的 HTML 注释；
散文标记脚本读不懂，而读不懂的结果是**误报**，误报的结果是被忽略。

### 落成脚本时的「守卫的守卫」

标记本身会写错。2026-09-07 `probes.md` 就出过 `start=3 / end=2`——
把标记「提到标题之前」时加了新的、没删旧的。

⚠️ **这个毛病的失败方向朝着「什么也不报」**：深度计数式实现下，
`probes.md` 结束时 depth=1，若不逐文件重置，按字母序排在它后面的
`roadmap.md` / `silent-risks.md` / `state.md` **会被整体豁免掉**。
0 处不是因为干净，是因为检查在半路闭了嘴。

**一个豁免机制出 bug，比检查本身出 bug 更糟：它让检查更安静，不是更吵。**

所以脚本必须自己断言：

1. 每文件 `start == end`，**不配平直接失败并指出文件名**
2. 不允许嵌套（深度只能是 0 或 1）
3. EOF 时深度归零
4. **逐文件重置块状态**，绝不跨文件带

⚠️ **禁语只防复发，不防首发。** 它是一份对自然语言的黑名单，而黑名单漏一条即静默失效。
禁语从**状态翻转那次提交里被删掉的字符串**中生成——列表由真实编辑长出来，
不由想象力长出来。**首次写出一句新的过期表述，仍然只能靠人眼。**
