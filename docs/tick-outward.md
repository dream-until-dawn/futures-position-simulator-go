# 通用涨跌停向外取整

## 设计与兼容边界

本批只增加调用方显式选择的算术能力：理论涨停价向上、理论跌停价向下对齐到最小变动价位。`TickOutward` 追加为枚举值 6，原有 0–5 的值及行为保持不变，不改 `MeasuredTickRounding()`，不作任何交易所实测或历史规则声明。开仓专用最小手数不在本批范围。

向外取整必须精确处理小于 decimal 默认除法精度的余数。新分支使用整数商和精确余数：正余数在上界加一跳，负余数在下界减一跳；整除保持原值。原有取整分支不调整。

回放包 `Settings.TickRounding` 使用已有整数 JSON 表示，新增值序列化为 6；无需改变包格式或内核存档格式。旧版本不认识值 6，仍应拒绝运行；向后兼容指新版本保留旧值的解释，不承诺旧程序认识新值。规则快照本身不存取整配置。

## 验证安排

先在旧实现运行枚举值 6 的行为测试，保存实际断言失败。覆盖分数跳、整除、零比例、极细余数、负理论下界、缺比例/昨结算/tick、未知枚举，及与既有取整方向的判别反例。锁定旧枚举数值、默认实测映射及回放 JSON 往返和运行入口。

新增定向破坏覆盖上界方向、下界方向、精度退化、有效性与显示名称，并要求编译成功后在对应断言检出、源码还原一致。完成三模块回归与 race，保存原始日志与准确提交；只推独立分支，不合并、不打 tag、不连接柜台。
